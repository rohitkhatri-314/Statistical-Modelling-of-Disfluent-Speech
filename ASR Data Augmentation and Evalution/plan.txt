# plan.md

## 1. Goal

Build a local, free pipeline that:

1. Takes clean LibriSpeech transcripts.
2. Converts them into stuttered/disfluent transcripts using the paper’s augmentation logic.
3. Generates clean and stuttered synthetic audio using an open-source TTS model.
4. Evaluates the generated speech using ASR + `WER` + `BERTScore`.

This pipeline will mainly support **synthetic stuttered speech creation and evaluation**, not ASR fine-tuning yet.

---

## 2. Scope

### Included

- Clean text ingestion from LibriSpeech.
- Text normalization.
- Disfluency augmentation:
  - word repetition
  - phrase repetition
  - interjections: `uh`, `um`
- Speech generation using HuggingFace SpeechT5.
- Multiple speaker embeddings for diversity.
- ASR inference using `facebook/wav2vec2-base-960h`.
- Evaluation using:
  - WER
  - BERTScore with `microsoft/deberta-large-mnli`

### Not included for now

- ASR fine-tuning.
- Real stuttering audio collection.
- Paid TTS APIs.
- Forced alignment or timestamp-level disfluency detection.

## 6. Disfluency Augmentation Logic

Follow the paper’s augmentation rules.

### 6.1 Word repetition

Select:

```text
1 to 3 words per utterance
```

Repeat each selected word:

```text
1 to 4 additional times initially
1 to 6 additional times in expanded setting
```

Example:

```text
clean:
my name is john

stuttered:
my my my name is john
```

---

### 6.2 Phrase repetition

Select:

```text
phrase length: 2 to 4 words
```

Repeat phrase:

```text
1 to 3 additional times initially
1 to 5 additional times in expanded setting
```

Example:

```text
clean:
my name is john

stuttered:
my name my name my name is john
```

---

### 6.3 Interjections

Insert:

```text
uh or um
```

Insertion locations:

```text
1 to 4 locations
```

Repeat interjections:

```text
1 to 4 times initially
1 to 7 times in expanded setting
```

Example:

```text
clean:
my name is john

stuttered:
my um um name is john
```

---

## 7. Augmentation Constraints

Adjust disfluency insertion based on utterance length.

Rules:

```text
Do not insert more disfluencies than the utterance can support.
Do not select phrases longer than the utterance.
Reduce repetition count for very short sentences.
Avoid overlapping events when possible.
```

Example:

```text
If utterance has only 2 words:
    do not insert 4 interjections
    do not use a 4-word phrase repetition
```

Models:

```text
TTS model:
microsoft/speecht5_tts

Vocoder:
microsoft/speecht5_hifigan

Speaker embeddings:
Matthijs/cmu-arctic-xvectors
```

Generate two types of audio:

```text
1. Clean synthetic speech
2. Stuttered synthetic speech
```

For each utterance:

```text
clean_text -> clean_audio
stuttered_text -> stuttered_audio
```

Use the same speaker for both versions so evaluation is fair.

## 12. Evaluation Pipeline

ASR model:

```text
facebook/wav2vec2-base-960h
```

Evaluation reference:

```text

```

```text

```

Metrics:

```text
WER
BERTScore
```

---

## 13. WER Evaluation

Use `jiwer` or a similar library.

WER compares:

```text
reference = original clean text
hypothesis = ASR transcription of generated audio
```

Compute:

```text
WER
substitutions
deletions
insertions
```

Example:

```text
reference:
my name is john

hypothesis:
my my my name is john

WER increases because of inserted repeated words.
```

---

## 14. BERTScore Evaluation

Use BERTScore to measure semantic similarity.

Model:

```text
microsoft/deberta-large-mnli
```

Inputs:

```text
candidate = ASR hypothesis
reference = original clean text
```

Output:

```text
BERTScore F1
```

Use the rescaled version where possible.

---

## 15. Evaluation Comparison

Compare two conditions:

```text
Clean synthetic speech ASR performance
vs
Stuttered synthetic speech ASR performance
```

Main comparison:

```text
WER_clean vs WER_stuttered
BERTScore_clean vs BERTScore_stuttered
```

Expected pattern:

```text
WER_clean < WER_stuttered
BERTScore_clean > BERTScore_stuttered
```

This shows how much disfluency affects ASR.
